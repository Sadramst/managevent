# Contributing

1. Pick an issue, or create one with `.github/ISSUE_TEMPLATE/agent-task.yml`.
2. Branch: `feat/<app>-<short-name>`.
3. Follow `AGENTS.md` (root) and the `AGENTS.md` in the folder you work in.
4. Open a PR using the template, link the issue, and include screenshots of the EN and FA (RTL) layouts for UI work.
5. CI must be green. At least one review is required, and two for `contract-change` PRs.

See `docs/agents/AGENT_WORKFLOW.md` for how human and AI agents split the work.
