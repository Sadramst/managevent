# Open decisions

Decisions that change the stack, money, privacy or scope. **Agents do not resolve these silently.** If your task touches one, comment on the issue and use the interim default. Closing the open ones is tracked as ROADMAP **DEC-04**; product decisions that are not stack-level (estimator rates, Free-plan plus-ones, a tax invoice for the Premium Event Pass) are ROADMAP **DEC-01** to **DEC-03**.
