# Open decisions

## Resolved on 2026-11-12

- **D-01 and D-02 are closed by [ADR-0011](adr/0011-production-on-single-sydney-vps.md).** Production runs on one Vultr VPS in Sydney with Docker Compose: the API, the worker, both web apps, Caddy and a self-managed PostgreSQL 16. The Step 2 choices (Fly.io `syd`, Supabase Sydney) were never provisioned and are superseded. The founder countersigns the ADR in the pull request that introduces it.
- **`embedded-postgres` at a beta-tagged version is allowed for local development only** by [ADR-0012](adr/0012-embedded-postgres-dev-exception.md).
